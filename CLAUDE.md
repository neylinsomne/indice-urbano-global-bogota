# Repo-local instructions for Claude Code

This file overrides global behavior for this specific repository
(`indice-urbano-global-bogota`). The instructions here have priority over
the global `~/.claude/CLAUDE.md`.

## Git commits

**NEVER** add `Co-Authored-By: Claude` or any `Co-Authored-By: ...anthropic...`
trailer to commits in this repo. This is a thesis/portfolio repository
intended to reflect the work of the author (Neyl Peñuela Bernate). All
commits must list only the author as the sole author.

Concretely:

- Do not include `Co-Authored-By:` lines for Claude in commit messages.
- Do not include "Generated with Claude Code" or similar attributions in
  commit messages, PR descriptions, or release notes.
- Inside source files, **never** add comments like `// Generated by Claude`
  or `# AI-assisted`.

If a user explicitly asks to add such attribution, ask for confirmation
first.

## Code style

- Comments in Spanish where the surrounding documentation/file is in
  Spanish; English where the file already uses English.
- The methodology document (`Doc_final.tex`) is the source of truth for
  any algorithmic decision; if code disagrees with the document, flag it
  before changing either.

## Scope of changes

- This repo is published under PolyForm Noncommercial 1.0.0. Avoid
  introducing dependencies under licenses incompatible with that
  (e.g. AGPL).
- No `.env` with real values should ever be committed; only `.env.example`
  with placeholders.
- Production credentials, Cloudflare tunnel configs, and any deployment
  secrets must remain outside this repo.
